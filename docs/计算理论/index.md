# 计算理论

计算理论的核心问题是，“**计算机的能力及其边界是什么？**”，也即“什么是计算可做到的，什么是计算不能做到的？”计算理论的三个核心领域是**<u>自动机理论</u>**、**<u>可计算性理论</u>** 和 **<u>计算复杂性理论</u>**。

自动机理论研究计算的形式系统及其性质，**<u>有穷计算机</u>** 和 **<u>上下文无关文法</u>** 是两个基础系统。

可计算性理论研究什么问题是可计算的、什么是不可计算的，也称递归论。这一领域始于20世纪前半叶哥德尔（Kurt Godel）、图灵（Alan Turing）和丘奇（Alonzo Church）的工作。

计算复杂性理论研究问题求解的计算难易程度及其原因，计算难度分类体系是这一领域的重要成果。
